# Average Interpoint Distance Wilcoxon Test

R code containing simulations, comparisons, and real data example related to the article https://arxiv.org/pdf/2408.10570.

## Contents

- `Utilities.R` – utility functions, helpers
- `Simulations.R` – simulation experiments
- `Real_Data_Example.R` – real data example
- `Further_Comparisons.R` – additional comparison scripts
- `Symmetrization_Exploratory.R` – exploratory symmetrization script


## Usage

Open the scripts in R and run them with the required packages installed.

## Reference

The code is based on the corresponding article and its supplement.
